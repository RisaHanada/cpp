# C++ OOP Projects
This folder contains object-oriented programming projects developed using C++.
Each project demonstrates concepts such as inheritance, polymorphism, encapsulation, and design patterns.

## PROJECTS
### 1. Bank Account System (Project Link: [oop-bank-account](https://github.com/RisaHanada/cpp/tree/main/oop-bank-account))  
A simple OOP-based banking module that models account data and operations.  
Includes validation, balance updates, and operator overloading to simulate deposits, and withdrawals.

### 2. Restaurant Ordering System (Project Link: [oop-restaurant-ordering-system](https://github.com/RisaHanada/cpp/tree/main/oop-restaurant-ordering-system))  
A menu‑driven ordering application that manages items, orders, and receipts.  
Demonstrates dynamic memory, input parsing, and object‑oriented menu/item design.

### 3. Dictionary Application (Project Link: [oop-dictionary](https://github.com/RisaHanada/cpp/tree/main/oop-dictionary))  
A text/CSV‑driven dictionary loader that supports searching, copying, moving, and managing word entries.  
Focuses on deep copying, Rule of 5, dynamic arrays, and robust parsing logic.

### 4. RPG Game Framework (Project Link: [oop-rpg-game](https://github.com/RisaHanada/cpp/tree/main/oop-rpg-game))  
A modular RPG combat system featuring templated character classes, weapons, abilities, and health types.  
Implements inheritance, templates, polymorphism, composition/aggregation, and full combat simulation.
